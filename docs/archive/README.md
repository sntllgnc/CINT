# Historical material

This directory preserves lineage and regression context outside the active CINT
product surface.

- `agent-floor-v0.1/` contains the historical Agent Floor narrative,
  architecture, security, privacy, release, adoption, and media material.
- `build-week-2026/` contains competition-specific judge and independent
  evaluation material.

The immutable source of release identity is the Git tag `v0.1.0-af-g0`. Archive
copies on the CINT successor branch are contextual references and do not alter
that tag or its evidence manifest.

Historical fixtures, protocol strings, AF error codes, deterministic demo, and
release evidence remain available for Adapter 01 compatibility tests. They do
not define CINT authority or product readiness.
